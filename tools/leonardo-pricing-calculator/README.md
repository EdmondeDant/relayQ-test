# Leonardo API 费用计算器

这是根据 Leonardo 已登录定价计算器在 2026-08-01 显示的数据独立实现的静态网页版本。

- 图片模型：32 个
- 视频模型：31 个
- 合计：63 个（当前 Leonardo 页面实际数量）
- 默认汇率：1 USD = 7.19 CNY，可在页面直接修改
- 图片：支持模型实际提供的质量、比例和尺寸档位
- 视频：支持模型实际提供的时长、比例和清晰度档位
- 连续时长滑块模型：使用页面最短和最长时长费率进行线性按秒计算

## 部署

将 `index.html` 和 `pricing-data.js` 一起上传到网站的同一目录，访问 `index.html` 即可。无需框架、构建工具或服务器接口。

## 更新费率

Leonardo 可能随时调整价格或上下架模型。所有费率集中在 `pricing-data.js`，更新该文件即可，不需要修改页面代码。

本项目是独立实现，不包含 Leonardo 的原始源码、品牌图片或私有接口。
